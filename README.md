# Kaasu releases

Release builds of **Kaasu**, a private budget & money tracker for India. This repository only hosts the
installable APK files and `update.json` that the app reads to offer over-the-air updates.
No source code and no user data live here.

**Install:** download the latest `Kaasu-x.y.apk` from [Releases](../../releases/latest) on your Android phone and open it.
After that, Kaasu updates itself: you'll see "Update available" in the app.
